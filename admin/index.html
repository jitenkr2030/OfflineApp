How It Works

Each key uses SHA-256 cryptographic validation bound to one device.

Key Format:

PREFIX-EEEE-FFFFFFFF-SSSS

  • EEEE = Expiry days since epoch (hex)
  • FFFFFFFF = First 8 chars of fingerprint
  • SSSS = SHA-256 signature (4 hex chars)

Validation checks:

  • Key prefix matches app
  • Fingerprint matches device
  • Signature cryptographically valid
  • Expiry date not passed
