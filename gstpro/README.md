# GSTPro - GST Billing, Invoice & Accounting System

A complete single-file GST billing, invoicing, and accounting
application for Indian businesses. Fully offline, runs in any
modern browser.

---

## Overview

GSTPro handles GST-compliant invoicing, customer and supplier
management, expense tracking, GST return preparation, and
financial reporting. All data stored locally in browser.

---

## Quick Start

1. Open index.html in your browser
2. Copy the Machine Fingerprint
3. Send to administrator
4. Receive license key
5. Paste key and click Activate
6. System loads with demo data

---

## Features

### Invoice Management
- GST-compliant tax invoices
- CGST/SGST/IGST auto-calculation
- HSN/SAC codes per item
- Multiple line items per invoice
- Amount in words (Indian numbering)
- Print invoices (A4 format)
- Invoice status tracking (Draft, Sent, Paid, Overdue)
- Credit/Debit notes

### Customer & Supplier Management
- GSTIN validation with checksum
- Auto-fill state from GSTIN
- Outstanding balance tracking
- Contact and address management

### Product Catalog
- HSN/SAC code assignment
- GST rate per product
- Stock tracking
- Multiple units of measurement

### GST Tools
- GST Calculator (Add/Remove/From Total)
- GSTIN Validator (15-character checksum)
- HSN/SAC Code Finder (35+ pre-loaded)
- GSTR-1 preparation and JSON export
- GSTR-3B summary calculation
- Input Tax Credit tracking

### Financial Management
- Payment tracking (receive and make)
- Purchase recording with ITC
- Expense management by category
- Profit & Loss statement
- Receivables aging report

### Reports & Analytics
- Sales report (monthly)
- Purchase report
- Expense report by category
- GST summary report
- Top customers chart
- Chart.js analytics

### Other Features
- Dark and light theme
- Command palette (Ctrl+K)
- Export/Import data (JSON)
- CSV export for invoices, payments, expenses
- 10 achievement badges
- Auto-save every 30 seconds
- PC-locked license system
