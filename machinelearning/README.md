# SIIT Machine Learning LMS

Complete offline learning platform for Machine Learning
with Python. 12 modules from ML foundations through
end-to-end projects. Built-in code editor, quizzes,
progress tracking, instructor panel, and certificates.

## Curriculum
1. ML Foundations & Python Setup
2. Data Preprocessing for ML
3. Linear Regression
4. Logistic Regression
5. Classification — KNN, Decision Trees
6. Random Forest & Ensemble Methods
7. Clustering — K-Means & DBSCAN
8. Model Evaluation & Selection
9. Feature Engineering
10. Neural Networks with Scikit-learn
11. Introduction to Deep Learning
12. End-to-End ML Project

## Features
- Interactive code editor (CodeMirror)
- Run Python code in browser (Pyodide)
- 5 quizzes per module (60 total)
- Progress tracking with charts
- Certificate generation
- Achievement badges
- Notes & bookmarks
- Dark/Light theme
- Command palette (Ctrl+K)
- Instructor panel (PIN: 8700189551)
- Fully offline after first load
