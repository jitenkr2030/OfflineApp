# DigiMktg Academy - Digital Marketing Course LMS

A complete single-file learning management system for digital marketing
with 12 modules, marketing calculators, funnel planner, and timed
assessments.

---

## Overview

DigiMktg Academy teaches digital marketing from fundamentals to advanced
strategy. Students learn SEO, Google Ads, Social Media, Content Marketing,
Email Marketing, Analytics, PPC, Influencer Marketing, Video Marketing,
E-commerce, and Campaign Planning.

No server, no database, no installation required.
Just open index.html in any modern browser.

---

## Quick Start

### For the Student

1. Open index.html in your browser
2. Copy the Machine Fingerprint shown on the activation screen
3. Send the fingerprint to your instructor
4. Receive a license key from your instructor
5. Paste the key and click Activate
6. Log in with your name and student ID
7. Start learning digital marketing

## Features

### 12 Course Modules

- Module 1: Digital Marketing Fundamentals (AIDA funnel, channels, SMART goals)
- Module 2: Search Engine Optimization (On-page, off-page, technical SEO)
- Module 3: Google Ads and SEM (Keywords, bidding, Quality Score)
- Module 4: Social Media Marketing (Facebook, Instagram, TikTok, LinkedIn)
- Module 5: Content Marketing (Blog writing, content types, distribution)
- Module 6: Email Marketing (Campaigns, automation, segmentation)
- Module 7: Google Analytics and Data (UTM, goals, custom reports)
- Module 8: PPC and Paid Advertising (Display, retargeting, budget)
- Module 9: Influencer Marketing (Tiers, negotiation, FTC disclosure)
- Module 10: Video Marketing (YouTube SEO, short-form video)
- Module 11: E-commerce and CRO (Cart recovery, A/B testing)
- Module 12: Strategy and Campaign Planning (Budget, timeline, reporting)

### Marketing Tools

- ROI Calculator (Revenue vs Cost)
- CPC Calculator (Cost per Click)
- CPM Calculator (Cost per Mille)
- Conversion Rate Calculator
- CPA Calculator (Cost per Acquisition)
- ROAS Calculator (Return on Ad Spend)
- Marketing Funnel Visualizer (Impressions to Revenue)

### Quiz System

- Timed assessments per module (15-25 minutes)
- Questions and options randomized each attempt
- 5 questions per module with explanations
- Detailed score breakdown after completion
- Pass threshold: 60 percent

### Student Features

- Login and registration
- Module prerequisites
- Bookmarks and personal notes
- 12 achievement badges
- Daily streak tracking
- Chart.js analytics
- Export and import data
- Command palette
- Dark and light theme

## Troubleshooting

License expired screen
    Contact administrator for a new license key

Different machine error
    Key was generated for another computer

Charts not showing
    Check internet connection for Chart.js CDN

Data lost after browser update
    Use Export feature to keep JSON backups
