# LinuxAdmin Pro LMS

Complete offline learning platform for Linux System
Administration. 12 modules from shell basics through
Docker containers and production server setup.

## Curriculum
1. Linux Architecture & Shell Basics
2. File Permissions & User Management
3. Process Monitoring & System Services
4. Storage & Filesystem Management
5. Networking & Secure Shell (SSH)
6. Shell Scripting Fundamentals
7. Package Management & Repositories
8. Log Management & Monitoring
9. Cron Jobs & Task Automation
10. Security Hardening & Firewall
11. Docker & Containerization
12. System Administration Capstone

## Features
- Interactive sandbox terminal (25+ commands)
- Virtual filesystem with 12 files/directories
- 5 quizzes per module (60 total)
- Progress tracking with charts
- Certificate generation
- 12 achievement badges
- Notes & bookmarks
- Dark/Light theme
- Command palette (Ctrl+K)
- Instructor panel
- License system with machine fingerprint
- Fully offline after first load

## Terminal Commands
pwd, ls, cd, mkdir, touch, cat, head, tail,
wc, grep, find, chmod, ps, top, df, du,
whoami, hostname, id, uname, date, echo,
free, uptime, history, clear, help
