# InstituteHub - Institute Management System

A complete single-file institute management system for
educational institutions with student management, staff management,
attendance, fees, examinations, library, and more.

---

## Overview

InstituteHub manages all aspects of an educational institute
from a single HTML file. No server, no database, no installation.
Just open index.html in any modern browser.

---

## Quick Start

### For the Student

1. Open index.html in your browser
2. Copy the Machine Fingerprint shown on the activation screen
3. Send the fingerprint to your administrator
4. Receive a license key from your administrator
5. Paste the key and click Activate
6. The system loads with demo data to explore

---

## Features

### Student Management
- Student directory with search and filters
- Add/edit/delete students
- Student profile with tabs (overview, fees, attendance)
- Course and batch assignment
- Export student list to CSV

### Staff Management
- Staff directory with role filters
- Add/edit staff records
- Department and role assignment
- Salary tracking

### Course & Subject Management
- Course creation with fee structure
- Subject management with teacher assignment
- Semester and credit tracking

### Attendance System
- Daily attendance by course and batch
- Mark all present/absent with one click
- Attendance percentage tracking
- Leave management

### Fee Management
- Record payments with receipt generation
- Multiple payment modes (Cash, UPI, Online, Cheque)
- Fee defaulters report
- Payment history per student
- Printable receipts
- Export payments to CSV

### Examinations
- Create exams with schedule
- Marks entry per subject
- Pass/fail status
- Result reports

### Timetable
- Weekly class timetable per course
- Teacher assignment per slot
- Visual grid layout

### Notice Board
- Post notices with priority levels
- Target audience selection
- Expiry dates

### Library
- Book catalog management
- Issue and return tracking
- Overdue detection

### Certificates
- Generate Bonafide, TC, Character certificates
- Auto-numbered
- Printable

### Reports & Analytics
- Student strength by course
- Gender distribution charts
- Attendance trend chart
- Fee collection chart
- Fee defaulters list
- Exam results report

### Dashboard
- Total students and staff
- Today's attendance
- Fee collection summary
- Pending fees
- Quick action buttons
- Chart.js analytics

### Settings
- Institute name and details
- ID prefix configuration
- Minimum attendance percentage
- Currency symbol
- Data reset option

### Security & Licensing
- PC-locked license system
- SHA-256 cryptographic validation
- Automatic data wipe on expiry

### Other Features
- Dark and light theme toggle
- Command palette (Ctrl+K)
- Export/import all data (JSON)
- 8 achievement badges
- Auto-save every 30 seconds
