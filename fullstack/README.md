# FullStack Academy - Web Development Learning Management System

A complete single-file LMS for learning full stack web development
with live code preview, 12 comprehensive modules, and PC-locked
license protection.

---

## Overview

FullStack Academy is a browser-based learning platform in a single
HTML file. It teaches HTML, CSS, JavaScript, React, Node.js, MongoDB,
REST APIs, Git, and Deployment. Students write code in a built-in
editor with live preview and take timed assessments.

No server, no database, no installation required.
Just open index.html in any modern browser.

---

## Quick Start

### For the Student

1. Open index.html in your browser
2. Copy the Machine Fingerprint shown on the activation screen
3. Send the fingerprint to your instructor
4. Receive a license key from your instructor
5. Paste the key and click Activate
6. Log in with your name and student ID
7. Start learning web development

## Features

### Live Code Editor

- Three-tab editor: HTML, CSS, JavaScript
- CodeMirror-powered with syntax highlighting for all three languages
- Live preview in real-time (updates as you type)
- Responsive preview modes: Desktop, Tablet, Mobile
- Run button to manually refresh preview
- Reset button to restore starter code
- Dracula theme for comfortable coding

### 12 Comprehensive Modules

- Module 1: HTML5 Fundamentals (Semantic tags, forms, accessibility)
- Module 2: CSS3 Styling (Flexbox, Grid, animations, responsive units)
- Module 3: JavaScript Basics (DOM, events, arrays, objects)
- Module 4: JavaScript Advanced (ES6+, async/await, Fetch, closures)
- Module 5: Responsive Web Design (Mobile-first, media queries)
- Module 6: React.js Fundamentals (Components, hooks, JSX)
- Module 7: Node.js and Express.js (Server, routing, middleware)
- Module 8: Databases (MongoDB, Mongoose, SQL basics)
- Module 9: REST API Design (JWT auth, endpoints, validation)
- Module 10: Git and Version Control (Branching, merging, GitHub)
- Module 11: Deployment (Docker, Vercel, CI/CD, environment vars)
- Module 12: Full Stack Project (Build a complete MERN app)

### Quiz System

- Timed assessments per module (15-30 minutes each)
- Questions and options randomized on each attempt
- 5 questions per module with explanations
- Detailed score breakdown after completion
- Pass threshold: 60 percent
- Time tracking for speed achievements

### Student Features

- Login and registration with session persistence
- Module prerequisites with sequential learning path
- Bookmarks for quick module access
- Personal notes per module
- 12 achievement badges
- Daily streak tracking
- Chart.js analytics (scores and completion)
- Export and import data as JSON
- Command palette (Ctrl+K)
- Keyboard shortcuts

### Instructor Features

- Instructor panel accessible from header
- Module editor to create and edit modules
- Question builder with explanations
- Announcement system

### Security and Licensing

- PC-locked license system (one key per machine)
- SHA-256 cryptographic key validation
- Anti-tamper protection on stored data
- Automatic data wipe on license expiry
- Periodic validation every 30 seconds

### User Interface

- Dark and light theme toggle
- Purple and cyan accent color scheme
- Sidebar navigation with icons
- Stats dashboard with 5 metric cards
- Toast notifications
- Command palette for quick navigation
- Responsive layout for desktop and tablet

## Security Notes

- The system cannot delete the HTML file from disk
- The system wipes all data and locks permanently on expiry
- For maximum security use server-side authentication

## Troubleshooting

License expired screen
    Contact instructor for a new key

Different machine error
    Key was for another PC, request a new one

Editor not loading
    Check internet connection for CDN resources

Live preview not working
    Check browser console for JavaScript errors

Charts not showing
    Check internet connection for Chart.js CDN

Data lost after browser update
    Use Export feature to keep JSON backups
