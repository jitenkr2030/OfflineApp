# SIIT Data Science & Analytics LMS

Complete offline learning platform for Python Data Science
& Analytics. 12 modules with code editor, quizzes, progress
tracking, instructor panel, and certificate generation.

## Curriculum
1. Python for Data Science
2. NumPy — Numerical Computing
3. Pandas — Data Manipulation
4. Data Cleaning & Preprocessing
5. Statistics & Probability
6. Matplotlib — Data Visualization
7. Seaborn — Statistical Visualization
8. Exploratory Data Analysis (EDA)
9. Introduction to Machine Learning
10. Linear & Logistic Regression
11. Classification & Clustering
12. Real-World Data Projects
